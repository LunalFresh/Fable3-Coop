# Fable III Co-op — v2.5.0

This release brings saved friend requests and in-game co-op controls to the supported Fable III PC build, powered by XLiveLessNess.

**Included:** friend requests with acceptance/cancel/decline, presence, direct joining, game invitations, host kicking, the Sanctuary-style menu, and the fix for deterministic duplicate network IDs at startup.

**Download:** `Fable3-Coop-v2.5.0.zip` and its SHA-256 file. Extract the complete ZIP, close the game, and run Setup.cmd on each PC. Existing profiles and friends are preserved. Use matching mod versions and game content.

**Compatibility:** Fable3.exe 1.1.1.3 / Patch 2 with the exact supported checksum. Tested on Windows 11, two players. Reachable IPv4 and UDP 39000–39001 are required; the mod does not configure router/NAT traversal.

**Validation:** joins/invitations with either PC hosting, friend-request lifecycle and persistence, leave/kick, and remote play with a location transition and rejoin have passed user testing. Six automated runtime checks passed. See VALIDATION.md for installation checks and limits.

The ZIP contains the mod, installer, documentation, licenses, and matching source folders. Game files and personal configuration are not included. This is an independent community release; please report reproducible issues with version and host/guest details.
